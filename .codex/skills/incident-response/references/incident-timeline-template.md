# 故障时间线与复盘模板

直接把下面内容复制到故障记录里逐项填写。**空着的字段比编造的字段有价值**——写"待确认"或"未定位"，不要为了填满而猜。

- 当前状态：已确认恢复 / 部分恢复 / 仍未恢复 / 尚未验证
- 记录人与角色：

## 六、根因结论

**复盘纪律：对事不对人，不用于追责。** 时间线只增不改；不确定就写"尚未验证"；不夸大恢复效果，也不掩盖没恢复的事实。
