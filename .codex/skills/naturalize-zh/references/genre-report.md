# 规则卡 · 工作汇报 / 周报 / 邮件

改写自由度**最低**的一类，但删减力度**最大**。

这类文本的结构（编号小节、称呼语、汇报格式）是收件人预期的一部分，动了会显得不专业。但它的内容里套话密度也是四类里最高的——「在团队的共同努力下」「为后续工作奠定了坚实基础」这种句子在周报里能占到三分之一篇幅。

所以口径是：**结构一动不动，内容往死里删。**

---

## 一、口语化档位：**零**

不做任何口语化。不用「说白了」，也不用「更狠」「够呛」这类在公众号里允许的词。

书面语不等于套话。「订单系统重构：完成核心模块梳理」是干净的书面语，「在团队的共同努力下各项工作有序开展」才是套话。删后者，不用把前者改成口语。

**唯一的例外**：如果原文是发给同级同事的即时消息或非正式邮件（有「Hi 各位」「兄弟们」这类称呼），允许保留原文本来就有的口语度，但**不主动增加**。

---

## 二、分段：**不动**

- 小节标题、编号（一、二、三 / 1. 2. 3.）**全部保留**
- 段落的归属不变——原文在「二、问题」下的内容，不能挪到「三、下周计划」
- 不合并小节，不新增小节

**唯一允许的结构改动**：小节内部的多个自然段可以合并（因为周报里的分段常常是为了凑篇幅）。

**一个小节被删空了怎么办**：保留标题，内容位置写 `[需补：…]`。不要因为内容空了就把整节删掉——收件人预期看到这一节，缺了会以为漏发。

---

## 三、标题：**只削套话尾巴，序号保留**

| 改前 | 改后 |
|------|------|
| `一、项目推进方面` | `一、项目推进` |
| `二、问题与挑战` | `二、问题` |
| `三、下周工作计划安排` | `三、下周计划` |
| `四、总结与展望` | 整节通常是空的，考虑连节带内容删或标注 |

序号（一、二、三）一律保留。「方面」「情况」「工作」「相关」这类尾巴可以削。

---

## 四、绝对不换的词

- **项目名、系统名、模块名**：「订单系统重构」不能改成「订单相关改造」
- **人名、部门名、职位称呼**
- **指标名**：「转化率」「P0 故障数」「SLA」不能换说法
- **数字和日期**：包括「本周」「下周」「Q3」这类时间指代
- **称呼语**：「各位领导好」保留（这是礼节，不是套话）

---

## 五、这一类特有的 AI 味高发点

按出现频率排序：

1. **「在团队的共同努力下」类**——「在…的努力下」「在…的支持下」「在…的指导下」。整个介词短语删掉。
2. **「为…提供了有力保障」类**——见通用清单第 16 条。整句删。
3. **空转句**——「持续推进相关工作」「进一步夯实基础」「确保各项任务保质保量完成」。这是周报里最大的一类。**删了要留标注**，因为那个位置本该有具体内容。
4. **四字格堆砌**——「有序开展」「齐心协力」「多措并举」「提质增效」。全删。
5. **「主要体现在…等方面」**——把「主要体现在」和「等方面」删掉，只留中间的实际内容。
6. **「针对上述问题，我们已积极采取相应措施」**——典型的说了等于没说。删掉后留 `[需补：具体措施]`。
7. **末尾的自我表扬段**——「本周工作进展顺利，团队协作高效」。整段删。
8. **「不仅…而且…」**——周报里用来把一件事说成两件事。

## 六、示范

### 改前

```markdown
## 本周工作总结

各位领导好，现将本周工作情况汇报如下：

**一、项目推进方面**

本周持续推进订单系统重构项目，在团队的共同努力下，各项工作有序开展。我们不仅完成了
核心模块的梳理，而且对现有架构进行了全面的评估分析，为后续工作的顺利开展奠定了坚实
基础。

**二、问题与挑战**

在推进过程中，我们也遇到了一些挑战。主要体现在跨团队协作效率有待提升、需求变更较为
频繁等方面。针对上述问题，我们已积极采取相应措施，持续优化工作流程。

**三、下周计划**

下周将继续深化推进相关工作，进一步夯实项目基础，确保各项任务保质保量完成。

总的来说，本周工作进展顺利，团队协作高效，为项目的成功交付提供了有力保障。
```

### 改后

```markdown
## 本周工作总结

各位领导好，本周工作汇报如下：

**一、项目推进**

订单系统重构：完成核心模块梳理，并对现有架构做了评估。
[需补：完成了哪几个模块、评估结论是什么]

**二、问题**

跨团队协作效率偏低，需求变更频繁。[需补：已采取的具体措施]

**三、下周计划**

[需补：下周的具体任务项——原文只有「深化推进」「夯实基础」，没有可执行内容]
```

### 这组示范演示了什么

- **结构一动不动**：三个小节、加粗序号、称呼语，全部原样保留
- **口语化为零**：改后文本仍是标准书面语
- 标题削尾巴：`一、项目推进方面` → `一、项目推进`；`二、问题与挑战` → `二、问题`
- 删掉的套话：在团队的共同努力下 / 各项工作有序开展 / 不仅…而且… / 全面的 / 为后续工作的顺利开展奠定了坚实基础 / 主要体现在…等方面 / 积极采取相应措施 / 持续优化工作流程 / 深化推进 / 夯实 / 保质保量 / 总的来说 / 团队协作高效 / 提供了有力保障
- **三处标注暴露了原文的空洞**：删完之后「下周计划」整节是空的。原稿看起来饱满，是因为套话把空洞填上了。

### 这一类的价值不在「更好读」，在「暴露真相」

公众号改完是更好看，周报改完常常是更难看——因为你会发现这周其实没干什么。

**这是功能，不是缺陷。** 不要为了让改后的周报「看起来充实」而保留套话，也不要自己补内容。原文是空的就让它显出空，`[需补：…]` 交还给作者去填。

### 破功版对照（不要这样改）

```markdown
**三、下周计划**

下周计划完成订单查询接口的性能优化，预计将 P99 从 800ms 降到 200ms 以内，
同时推进支付模块的联调工作。
```

原文的「三、下周计划」整节只有「深化推进相关工作，夯实项目基础」，没有提到任何接口、任何数字、任何模块。上面这一版全是编的。

它读起来像一份好周报，但它是假的。
