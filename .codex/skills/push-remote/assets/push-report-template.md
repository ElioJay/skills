# 推送交付报告模板

推送完成后按本模板输出。**状态必须与事实一致**，不要为了好看写成"已推送"。

## 推送目标

- remote：`origin`（`https://github.com/<owner>/<repo>.git`）
- 分支：`<branch>` → `origin/<branch>`
- 动作：快进推送 / 首次推送分支 / 同步后推送 / 安全强推

## 本次上传的提交

```text
<sha> <subject>
<sha> <subject>
```

（来自 `git log --oneline @{upstream}..HEAD`；无提交时写"无新提交，已是最新"。）

## 执行的命令

```bash
git push
```

（照实写。含 `--force-with-lease` 等高风险参数时必须同时写明用户已确认。）

## 推送后验证

- 本地 `HEAD`：`<sha>`
- 远程 `origin/<branch>`：`<sha>`
- 领先提交数：0（或说明剩余数量及原因）
- 工作区未提交改动：已排除 / 无
- CI 或 hook：通过 / 失败 / 未触发（写明依据）

## 结果状态

从以下三者中选一个，不含糊：

- **已推送到远程**：远程 ref 已更新为预期 SHA。
- **仅本地提交**：推送未执行或被拒，改动仍在本地。
- **推送被拒未生效**：远程状态未改变。

## 未完成与需授权事项

- 需要用户确认才能执行的动作（强推、推送 tag、删除远程分支、改 remote 配置）。
- 未验证的部分及其原因（如无 CI 访问权限、网络不可达）。
