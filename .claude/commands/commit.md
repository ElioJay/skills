为当前改动创建一次 git 提交。

## 步骤

1. 并行运行 `git status` 与 `git diff`（含已暂存与未暂存），了解全部改动。
2. 参考 `git log` 最近几条，沿用本仓库的提交信息风格。
3. 起草提交信息：
   - **使用英文**。
   - 一行简洁主题（动词开头，如 `add` / `update` / `fix` / `refactor`），必要时空一行写正文说明"为什么"。
4. 暂存相关文件（按文件名精确添加，避免 `git add -A`），创建提交。
5. 运行 `git status` 确认提交成功。

## 约束

- 只在**当前分支**操作，不创建新分支。
- 不提交疑似含密钥的文件（`.env`、`local-config.json` 等）；如用户坚持要提交需先警告。
- 没有任何改动时不要创建空提交。
- 未经用户明确要求，不要 `git push`。
