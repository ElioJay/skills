# 安全约束规则

会话开始即加载，适用于本仓库所有改动。

## 密钥与敏感信息

- 不在代码、脚本、配置或文档中硬编码任何密钥、令牌、口令、私有 URL。
- 敏感值一律走 `local-config.json`（已被 `.gitignore` 忽略）或环境变量；仓库内只保留 `*.template.json` 模板。
- 提交前若发现疑似密钥的文件被暂存，必须先警告用户，不可径直提交。

## 危险操作

- 不批量删除文件/目录；任何删除操作需用户确认（见全局规则）。
- 不擅自执行 `rm -rf`、`git push --force`、`git reset --hard`、`git clean -f` 等破坏性命令（已由 `hooks/guard-bash.ps1` 拦截）。
- 不创建新分支、只在当前分支操作（见全局规则）。

## 脚本安全

- PowerShell 脚本对外部输入（stdin、参数、文件内容）做基本校验，避免命令注入。
- 语法检查用 Parser API（`hooks/check-ps1.ps1`），不要为校验而执行不可信脚本。
