# REQ-012 下单

## 1. 背景

用户在商品详情页选好数量后下单，下单后需要尽快完成支付。

## 2. 角色

- 已登录用户

## 3. 需求条目

3.1 已登录用户选择商品和数量后提交订单，库存充足时下单成功，返回订单号并扣减库存。

3.2 库存不足时下单失败，提示“库存不足”，库存和订单都不变。

3.3 订单创建后超时未支付的，自动取消并释放库存。

3.4 同一个请求号重复提交时，返回第一次生成的订单，不重复扣减库存。

3.5 未登录用户不能下单，点击下单时跳转到登录页。

3.6 单次购买数量为 1 到 99 件。

## 4. 非功能

- 下单接口 P99 响应时间小于 300ms。
