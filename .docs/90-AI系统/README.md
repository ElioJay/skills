# 90-AI系统

**组**：AI 系统研发，项目本身要做 AI 功能时，在 8 个阶段之上多出来的过程，表外新增。放在最后，作为生命周期的扩展。

| 目录 | 活动 | 典型产出 |
|---|---|---|
| `91-知识获取` | 知识获取 | 领域知识梳理、规则库、标注规范 |
| `92-数据工程` | AI 数据工程 | 数据说明、质量评估、来源与血缘 |
| `93-模型开发` | 模型开发 | 模型卡、训练与调优方案、实验记录 |
| `94-模型评估` | 模型评估 | 评估报告：指标、偏差、鲁棒性 |
| `95-持续确认` | 持续确认 | 监控方案、漂移报告、再训练触发条件 |
| `96-影响评估` | AI 系统影响评估 | 对个人、群体、社会的影响评估 |
| `97-透明信息` | 面向相关方的信息 | 技术文档、用户说明、事件通报 |

与 `00-AI开发` 的分工：`00` 管"用 AI 做软件"，`90` 管"做的软件里有 AI"。不做 AI 功能的项目，整组保留 README 即可，或整组删掉。

**参照标准**：ISO/IEC 5338:2023（在 ISO/IEC/IEEE 12207 之上新增知识获取、数据工程、持续确认等 AI 过程）；ISO/IEC 42001:2023 附录 A.5 到 A.8。过程名依据公开摘要整理，落地前对照标准原文核对。
