# 20-需求工程

**阶段**：需求。回答"做什么"。

| 目录 | 表中活动 | 典型产出 |
|---|---|---|
| `21-需求调研` | 需求调研与获取 | 原始需求、截图、调研纪要 |
| `22-分析建模` | 分析建模 | 用例、流程图、领域模型 |
| `23-需求规格` | 编写规格 | 需求规格、原型、验收标准 |
| `24-需求评审` | 需求评审 | 评审记录与结论 |
| `25-需求基线` | 建立基线 | 基线清单、规格快照 |
| `26-变更管理` | 之后走变更管理 | 变更单、影响分析 |

**出口条件**：需求评审通过并基线化，验收标准可测。
