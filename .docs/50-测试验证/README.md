| 目录 | 表中活动 | 典型产出 |

| `51-测试设计` | 测试计划与用例 | 测试计划、用例、测试数据 |
| `52-集成测试` | 集成测试 | 联调记录、集成测试报告 |
| `53-系统测试` | 系统测试 | 系统测试报告、缺陷统计 |
| `54-性能安全` | 性能与安全测试 | 压测报告、安全扫描报告 |
