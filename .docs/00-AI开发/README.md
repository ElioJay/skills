## 提示词管理规范

- 一个提示词一个文件，固定五段：`## role`、`## 上下文`、`## 任务`、`## 约束`、`## 输出格式`。
- 可变部分用 `<占位符>` 标出，不把某次任务的具体值写死在模板里。
- 以 `02-提示词库/00-通用模板.md` 为基底，场景或模块提示词只写差异。
- 提示词里引用的文档路径一律用项目相对路径（如 `.docs/30-系统设计/...`），目录改名时同步。
- 改动提示词在文件末尾记一行：日期、改了什么、为什么。
- 提示词与技能的关系：提示词是一次对话的输入；技能是可按需加载、含 SKILL.md 的目录，能带脚本与参考文件。反复使用且带流程的提示词，升格为技能，记录在 `03-技能工具`。

**参照标准**：ISO/IEC 42001:2023 附录 A（AI 政策、内部组织、使用、第三方关系）；Agent Skills、MCP、AGENTS.md 开放规范。
